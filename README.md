Meu Currículo — Adriano Quimisse

1. Descrição

Site pessoal de currículo e portfólio desenvolvido para o Trabalho Prático I de Programação de Design Web.


O projeto utiliza HTML5 e CSS3 puro, sem JavaScript e sem frameworks de CSS.


2. Estrutura


index.html — apresentação pessoal, competências, vídeo e áudio.

about.html — currículo, formação, competências, tabela e certificados.

portfolio.html — grelha de projetos construída com CSS Grid.

hobbies.html — hobbies organizados com Flexbox.

contact.html — formulário completo com validação nativa HTML5.

css/estilo.css — estilos gerais e partilhados.

css/responsivo.css — media queries para tablet e telemóvel.

assets/img/ — fotografias, certificados e imagens dos projetos.

assets/video/ — vídeo local.

assets/audio/ — áudio local.

assets/ficheiros/ — CV e outros anexos.

4. Como visualizar

Abra o ficheiro index.html num navegador moderno. Todas as páginas estão ligadas pelo menu de navegação.


5. Multimédia

O projeto possui referências para:



fotografia de perfil;

imagens de projetos e hobbies;

vídeo MP4;

áudio MP3.


Substitua os ficheiros de exemplo da pasta assets/ pelos seus ficheiros reais, mantendo os nomes ou atualizando os caminhos no HTML.


6. Personalização

Antes da entrega, confirme:



nome completo e turma;

fotografia real;

email;

telefone;

formação académica;

projetos reais;

certificados;

ficheiro de vídeo;

ficheiro de áudio;

links das redes sociais.
